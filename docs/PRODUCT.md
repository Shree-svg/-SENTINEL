# SENTINEL – Product Overview

**Surface type:** product (dashboard/tool)

**Audience:** VIT Chennai academic reviewers and live demo audience. The dashboard must look polished, professional, and safety‑first.

**Voice:** calm, safety‑first, data‑dense but readable. Every label and tooltip should reassure the user while presenting the necessary metrics.

**Anti‑references:**
- No purple‑blue gradients.
- No cards‑inside‑cards layout.
- No generic Bootstrap look.
- No animation on every 2‑second poll cycle (only state‑change animations).

**Key selling points**
- Real‑time gas‑leak monitoring with ML‑driven classification.
- Role‑based views (Resident, Caregiver, Admin) with appropriate controls.
- Color‑coded status (green/amber/red) enforced everywhere.
- Persistent disclaimer: “This system supplements, not replaces, certified gas‑safety practice.”
- WCAG 2.1 AA accessibility.
