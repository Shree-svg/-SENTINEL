# 5.4 Sequence & Activity Diagrams

## 5.4.1 — Normal Telemetry Ingestion Sequence

```mermaid
sequenceDiagram
    participant FW as Arduino Nano<br/>(Firmware)
    participant BRIDGE as Ingestion Bridge<br/>(server/index.js)
    participant PIPE as Analytical Pipeline<br/>(pipeline.ts)
    participant UI as React Dashboard<br/>(LiveStatusPanel)
    participant RES as Resident

    loop Every 1.0 second
        FW->>FW: analogRead(A0) → gasValue
        FW->>FW: dht.readTemperature() / readHumidity()
        FW->>FW: Compute alarmState (skip if WARMUP_TIME_MS elapsed)
        FW->>FW: XOR checksum → NMEA frame
        FW->>BRIDGE: "$S,seq,gas,temp*10,rh*10,alarm*CS\n" over USB CDC 9600 Bd
    end

    BRIDGE->>BRIDGE: parseFrame(raw) → validate checksum
    BRIDGE->>BRIDGE: Store Reading in circular buffer (last 100)
    BRIDGE->>BRIDGE: signalAnalytics.analyzeReading() (server-side)

    UI->>BRIDGE: GET /api/readings/latest (polling ~1s)
    BRIDGE-->>UI: { gas, temp, rh, seq, alarm, compensatedGas, slope, ttd, ... }

    UI->>PIPE: pipeline.process(Reading)
    PIPE->>PIPE: 1. Calibration check (10 warm-up samples)
    PIPE->>PIPE: 2. Compute steamDeduction = min(250, K_RH·ΔRH + K_T·ΔT)
    PIPE->>PIPE: 3. compensated = gas − steamDeduction
    PIPE->>PIPE: 4. Slope estimation over 10-sample residual window
    PIPE->>PIPE: 5. TTD = (500 − compensated) / slope if slope > 0.3
    PIPE->>PIPE: 6. Classify: SAFE / BENIGN_STEAM / LEAK_SUSPECTED / GAS_LEAK / SENSOR_FAULT
    PIPE->>PIPE: 7. Debounce (3 consecutive GAS_LEAK → latch)
    PIPE->>PIPE: 8. Update FSM level: NORMAL → WARNING → ALARM → ESCALATED → EMERGENCY
    PIPE-->>UI: Analysis { cls, level, compensated, residual, slope, timeToDanger, events }

    UI->>RES: Render classification banner, dual-trace chart, escalation stepper
```

## 5.4.2 — Gas Leak Detection & Escalation Sequence

```mermaid
sequenceDiagram
    participant FW as Firmware
    participant BRIDGE as Bridge Server
    participant PIPE as Pipeline
    participant UI as Dashboard
    participant RES as Resident
    participant CG as Caregiver
    participant EMRG as Emergency (112)

    FW->>FW: gasValue > 300 ADC → alarmState = 1
    FW->>FW: Buzzer D8 HIGH, LED D9 HIGH (hardware safety floor)
    FW->>BRIDGE: Telemetry packet with alarm=1

    BRIDGE->>BRIDGE: Store alert event
    UI->>BRIDGE: GET /api/readings/latest
    BRIDGE-->>UI: Reading with high gas value

    UI->>PIPE: pipeline.process(reading)
    PIPE->>PIPE: compensated ≥ 300 OR residual ≥ 150 → cls = GAS_LEAK
    PIPE->>PIPE: confirm++ (debounce counter)
    Note over PIPE: confirm ≥ 3 → latched = true → smartAlarm = true

    PIPE->>PIPE: level → ALARM
    PIPE-->>UI: Analysis { cls: GAS_LEAK, level: ALARM, alarmTicks: 1 }
    UI->>RES: 🔴 ALARM banner, pulsing animation, escalation stepper at step 3

    Note over RES: 15 seconds pass without acknowledgment
    PIPE->>PIPE: alarmTicks ≥ 15 → level = ESCALATED
    PIPE-->>UI: Analysis { level: ESCALATED }
    UI->>CG: SMS / Email: "⚠ Gas alarm unacknowledged at [address]" (simulated in demo)
    UI->>RES: Escalation stepper at step 4, countdown to 112

    Note over RES: 30 seconds pass — still unacknowledged
    PIPE->>PIPE: alarmTicks ≥ 30 → level = EMERGENCY
    PIPE-->>UI: Analysis { level: EMERGENCY }
    UI->>CG: 112 emergency dispatch prompt shown
    UI->>EMRG: (Simulated in demo — real dispatch requires production auth)

    RES->>UI: Click "Acknowledge Alarm" button
    UI->>PIPE: pipeline.ack()
    PIPE->>PIPE: acked = true → level = ACKNOWLEDGED
    UI->>BRIDGE: POST /api/alerts/:id/acknowledge
    BRIDGE-->>UI: 200 OK
    PIPE-->>UI: Analysis { level: ACKNOWLEDGED }
    UI->>RES: Banner returns to SAFE / WARNING state
```

## 5.4.3 — Demo Simulator Activation Activity Diagram

```mermaid
flowchart TD
    START([Resident Clicks 'Demo Readings' Toggle]) --> CHECK_HW{Is real Arduino\nhardware connected?}
    CHECK_HW -->|Yes| BLOCK[Show hardware lock warning\nDemo blocked — real device active]
    CHECK_HW -->|No| SEL[Show Scenario Selector\nnormal / steam / cooking / gas_leak\nadc_saturation / sensor_fault]
    SEL --> SETSCEN[POST /api/demo/scenario]
    SETSCEN --> START_DEMO[POST /api/demo/start]
    START_DEMO --> GEN["DemoSimulator.generateFrame()\nat 1 Hz interval"]
    GEN --> INJECT[Inject synthetic Reading\ninto Bridge telemetry buffer]
    INJECT --> LABEL[Tag frame: isDemo = true]
    LABEL --> UI_RECV[Dashboard polls GET /api/readings/latest]
    UI_RECV --> PIPE_PROC[Pipeline.process() — normal analysis]
    PIPE_PROC --> RENDER[Render live chart & classification]
    RENDER --> CHECK_REAL{Real device\npacket received?}
    CHECK_REAL -->|Yes| PREEMPT[PREEMPT: stop demo immediately\nDisplay 'Real device detected' toast]
    CHECK_REAL -->|No| CHECK_STOP{User clicks\nStop Demo?}
    CHECK_STOP -->|No| GEN
    CHECK_STOP -->|Yes| STOP[POST /api/demo/stop]
    STOP --> CLEAR[Clear telemetry buffer\nReset UI toggle]
    CLEAR --> END([End])
    PREEMPT --> END
    BLOCK --> END
```

## 5.4.4 — Pipeline Compensation Activity Diagram

```mermaid
flowchart TD
    A([Raw Reading Received\ngasValue, temp, rh]) --> B{Sensor Fault?\nrh < 0 OR temp < −40?}
    B -->|Yes| FAULT["cls = SENSOR_FAULT\ncomp = raw (bypass)"]
    FAULT --> WARNLEVEL[level = WARNING]

    B -->|No| C{ADC Saturated?\ngas >= 1023}
    C -->|Yes| D["cls = GAS_LEAK\nsaturated = true\ncomp = 1023"]
    C -->|No| E{Calibration\nComplete?\n≥ 10 samples?}

    E -->|No| F[Push to calibration buffer\ncal.g, cal.h, cal.t\nReturn CALIBRATING state]
    E -->|Yes| G[Compute environmental deltas\nΔRH = max(0, rh − RH₀)\nΔT = max(0, temp − T₀)]

    G --> H["steamDeduction = min(250,\nmax(0, 2.8·ΔRH + 1.2·ΔT))"]
    H --> I["compensated = max(0,\ngas − steamDeduction)"]
    I --> J[residual = compensated − baseline_gas]
    J --> K[Append to 10-sample residual buffer]
    K --> L["slope m = Least-Squares(resBuf)"]
    L --> M{slope > 0.3\nAND comp < 500?}
    M -->|Yes| N["TTD = (500 − comp) / slope\ncapped at 600s"]
    M -->|No| O[TTD = null]

    N & O --> P{Classification\nDecision}
    P -->|"comp ≥ 500 OR residual ≥ 150"| Q["GAS_LEAK"]
    P -->|residual ≥ 60| R["LEAK_SUSPECTED"]
    P -->|naiveAlarm OR ΔRH > 5| S["BENIGN_STEAM\n(false alarm suppressed)"]
    P -->|otherwise| T["SAFE"]

    Q & R & S & T --> U{Debounce\nconfirm ≥ 3 consecutive\nGAS_LEAK?}
    U -->|Yes| LATCH["latched = true\nsmartAlarm = true"]
    U -->|No| UNLATCH{Previously latched\nAND residual < 30?}
    UNLATCH -->|Yes| RESET["latched = false\nsmartAlarm = false"]
    UNLATCH -->|No| KEEP[Keep current latch state]

    LATCH & RESET & KEEP --> FSM[Update Escalation FSM]
    FSM --> RET([Return Analysis Object])
    FAULT & D --> FSM
    WARNLEVEL --> FSM
```
