## 5.6.1 — Application Navigation Structure

```mermaid
flowchart LR
    ROOT["/ (redirect)"] --> MONITOR

    subgraph SHELL["App Shell — Persistent Header (Shell.tsx)"]
        NAV["🛡️ SENTINEL | [Status Beacon] [HW Port] | [Demo Toggle + Scenario Select]"]
        TABS["📊 Monitor | 🕐 Alerts | 💚 Caregiver | ⚙️ Admin | 🔔 Settings"]
    end

    SHELL --> MONITOR["/monitor\nLive Status Panel"]
    SHELL --> ALERTS["/alerts\nAlert History"]
    SHELL --> CAREGIVER["/caregiver\nCaregiver Portal"]
    SHELL --> ADMIN["/admin\nAdmin Calibration"]
    SHELL --> SETTINGS["/settings\nNotification Settings"]
```
