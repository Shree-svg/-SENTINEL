## Actor Descriptions

| Actor | Type | Description |
| :--- | :--- | :--- |
| **Resident (Occupant)** | Primary Human | Lives in the monitored space. Views the real-time dashboard, acknowledges alarms, and can toggle the demo simulator. |
| **Caregiver** | Secondary Human | Remote family member or carer with read-only access. Receives escalated SMS / email alerts and can invoke emergency services. |
| **Admin / Engineer** | Privileged Human | Tunes compensation gains, labels historical datasets, configures notification delivery, and runs benchmark evaluations. |
| **Arduino Nano** | Hardware Actor | Autonomous embedded device that senses the physical environment and enforces the deterministic hardware safety floor. |
| **Demo Simulator** | System Actor | Generates synthetic realistic telemetry streams for academic demonstrations and hardware-independent testing. |
